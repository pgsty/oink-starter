Gardez les prérequis courts, précis et vérifiables.

## Outils {#tools}

- Un système d’exploitation pris en charge.
- Git pour récupérer les sources.
- La version d’exécution requise par votre projet.

## Vérifier {#verify}

Donnez une commande par prérequis :

```console
$ project --version
project 0.1.0
```

Remplacez cette commande fictive par la vôtre avant publication.
