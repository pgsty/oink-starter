Ce tutoriel modèle une tâche complète : préparer, modifier, vérifier et relire.

## Partir d’un état connu {#known-state}

```bash
git status --short
git switch -c docs/first-change
```

## Modifier une seule chose {#change}

Changez une chaîne visible ou une petite valeur de configuration. La première tâche doit rester assez ciblée pour que son résultat soit évident.

## Vérifier {#verify}

Exécutez le contrôle pertinent le plus petit, puis ouvrez la surface modifiée et inspectez-la vous-même.
